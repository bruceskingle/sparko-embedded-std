# Demos of bruce-embedded-std for each board

A demo for each board bruce-embedded-std supports, showing its screen, lights and buttons working, and its settings
page and device API, to try a board before building firmware of your own on the platform.

Each release attaches a demo for each board. Flash one to a board plugged in by USB with bruce-embedded-flash's
window, or any app which flashes these boards, e.g. Marco Sparko's Devices page.
